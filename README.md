# Vines Financial Agent — GitHub Pages legal notices

Upload `index.html`, `privacy.html`, and `terms.html` to the root of a **public** GitHub repository and enable GitHub Pages using Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Before publishing — REQUIRED

1. Replace **every** occurrence of `REPLACE_WITH_CONTACT_EMAIL` in `privacy.html` and `terms.html` with a public company contact email address. This is the only required in-file placeholder; no GitHub username is required inside the HTML files.
2. Confirm that `Vines Medical PC` is the correct legal operator and that the described actual deployment, data retention, and technical controls are accurate. Update anything that does not match reality.
3. Have a qualified attorney review the notices before relying on them as final legal documents. These templates do not establish Intuit compliance or substitute for an Intuit security assessment.
4. Check all links after Pages deploys.

## GitHub Pages URLs

With repository `vines-financial-agent-legal` at account `YOUR_USERNAME`, URLs will be:

- `https://YOUR_USERNAME.github.io/vines-financial-agent-legal/`
- `https://YOUR_USERNAME.github.io/vines-financial-agent-legal/privacy.html`
- `https://YOUR_USERNAME.github.io/vines-financial-agent-legal/terms.html`

For Intuit, use the `privacy.html` URL as the Privacy Policy URL and the `terms.html` URL as the End-user License Agreement URL.

**Important:** GitHub Pages here is just the public legal-notice website; it is *not* the OAuth callback. Production OAuth redirect URI must be configured separately.

No JavaScript, remote fonts, third-party analytics, site cookies, financial records, or credentials are included in these three pages.
